# TOEIC Part 2 BEAT

TOEIC Listening Part 2（応答問題）を、ネオンアーケードゲームのような高速ループで反復するローカルファーストPWAです。

## 主な機能

- 50問のオリジナルPart 2問題（標準20・上級20・高難度10）
- ブラウザ音声による問題自動再生とA/B/C即時回答
- 正解時のパーティクル、COMBO、FEVER、XP、LEVEL UP
- 「？」による自信なし記録とWeak Score
- Weak Point、問題別統計、Daily Goal、Streak
- Web Speech APIによるSpeaking採点（GOOD / GREAT / PERFECT）
- IndexedDB保存、永続ストレージ申請、Service Worker、PWAアイコン

## 公開

リポジトリ名を `toeic-part2-beat` とし、GitHub Pagesを有効にすると次のURLで動作する構成です。

`https://yuuuh26.github.io/toeic-part2-beat/`

静的ファイルのみで動作し、ビルド工程は不要です。
